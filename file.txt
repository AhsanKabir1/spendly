Task 2: Create Terms and Conditions Page

1. Add a new route in app.py:

GET /terms

The route should render:

templates/terms.html


2. Create templates/terms.html with generic Terms and Conditions content appropriate for Spendly, a personal expense tracking app.

Include the following sections:

- Acceptance of Terms
- Use of Service
- User Data
- Limitations of Liability
- Changes to Terms

Extend base.html if it exists. Otherwise, match the style of landing.html.


3. In templates/landing.html, update the "Terms and Conditions" footer link:

Change:

<a href="#">Terms and Conditions</a>

To:

<a href="/terms">Terms and Conditions</a>

Do not modify the Privacy Policy link.


4. Commit the changes:

git add app.py templates/terms.html templates/landing.html
git commit -m "Landing add terms and conditions page and route"
